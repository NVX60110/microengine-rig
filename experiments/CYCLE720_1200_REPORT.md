# 1200-rpm staged 720-CAD experiment

This artifact is a single operating point, not an RPM campaign. It uses the
accepted Beta 2.6 fixed-wall anchor: 8.5 x 7.0 mm, CR 7.75, 3.0 bar/300 K
intake, phi 0.40, DME/CH4 25/75, 560 K wall, Zhao sk39, 3 µm annular
clearance and eccentricity 0.5. The reacting kernel uses `rtol=1e-9` and
`atol=1e-15` through the explicitly retained `TwoZoneOptions`.

The cycle convention is `-360..+360 CAD`: intake TDC=-360, firing TDC=0,
expansion BDC=+180 and exhaust end=+360. The four-stroke period at 1200 rpm
is 100 ms; the wrapped reacting segment is one revolution/50 ms.

## Staging and gates

1. `disabled-regression`: direct call to the canonical two-zone solver; this
   must pass before open-system output is considered.
2. `valves`: fixed-speed intake/exhaust effective-area flow and natural
   residual carry-over, with pumping work reported.
3. `friction`: adds the existing 0.15-bar central FMEP screening assumption.
4. `dynamics`: adds explicit speed integration; no motor torque is enabled in
   this bounded run unless a future controlled experiment opts into it.

The script stops after the first unresolved periodic state or numerical
failure. Periodicity requires relative mass, maximum species, relative
enthalpy, temperature and speed deltas to pass their declared tolerances.
Each stage records intake/exhaust mass, pumping work, friction work, gas work,
and per-cycle closure deltas. A failed stage is not relabeled as a physical
idle failure; it is `unresolved_periodic_state` or `numerical_failure` within
this project model.

## Reproduction

From the repository root:

```bash
python scripts/run_cycle720_1200_experiment.py
```

The generated `results/cycle720_1200_staged.json` is the machine-readable
artifact. No CFD, RPM sweep, fuel optimization or chemistry retuning is used.

## Observed result (project-model calculation)

The disabled-regression bridge passed against an independent same-process
canonical call. At the selected 2 CAD output step, the maximum pressure,
temperature and signed work differences were zero to the stored floating-point
precision. The bridge runtime was approximately 9.3 s on the development
machine.

The valve-enabled stage ran four complete 720-CAD cycles in approximately
80.4 s and stopped with status `unresolved_periodic_state`; friction and crank
dynamics were not enabled because the preceding stage did not close. The final
cycle deltas were approximately:

| quantity | cycle-to-cycle delta |
|---|---:|
| relative mass | 3.19e-2 |
| maximum species mass fraction | 1.11e-4 |
| relative specific enthalpy | 1.14e-2 |
| temperature | 6.65 K |
| speed | 0 rpm (prescribed) |

The failed gates were mass, species, enthalpy and temperature. The signed
cycle summary at the final stage was 1.995 bar PMEP, 5.787 bar gas-work MEP,
and 0 friction MEP. Intake/exhaust transferred 1.476/1.293 mg in the final
cycle; these values are generated by the assumed 1.0 mm² effective valve area,
timings and `Cd=0.70`, not measurements. The positive signed PMEP is retained
as a result of this open-system screen, not silently relabeled as a pumping
loss.

This is not evidence for or against a 1200-rpm stable idle. It identifies the
first unresolved model gate: the current single-zone open-system wrapper does
not yet produce a converged residual state under the declared valve closure.
The next implementation should inspect valve timing/area and energy/state
mapping in a nonreacting staged test before enabling any friction or motor
claim. No coefficient was tuned to force convergence.
Valve effective area (`1.0 mm²`), timing (`-360..-160` intake and
`160..360` exhaust), `Cd=0.70`, manifold states and friction bracket are
project-model assumptions pending pressure/flow and motoring measurements.
